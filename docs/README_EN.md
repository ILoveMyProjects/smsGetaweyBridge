## v0.2 Admin panel

Use **SMS Bridge** from Home Assistant's sidebar to manage saved recipient groups, named templates and activity logs. Webhooks are optional and require a locally trusted HTTPS endpoint. The SMS gateway is still directly connected to Home Assistant and any independent Ubuntu manager. No Ubuntu proxy or SSH access to Android is used.

See [main English README](../README.md) for workflow configuration and limitations.
